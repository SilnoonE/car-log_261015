# 공개 범위

| 구성 | 공개 방식 |
| --- | --- |
| 네 화면과 네이티브 UI | 실제 화면 코드를 공개용으로 정리 |
| 입력폼·검색·필터·차트·기본 합계 | 공개 |
| 데이터 모델·기본 입력 검증 | 공개 |
| SQLite 영구 저장·스키마·복원 | 원본을 제외하고 메모리 데모로 교체 |
| 파일 백업·복원·CSV 처리 | 실제 처리 코드를 제외하고 안내만 표시 |
| 실제 연비 계산 | 핵심 구현과 호출 제거 |
| 광고 SDK·동의 처리·노출 정책 | 원본 제외, 광고를 실행하지 않는 대체 코드 |
| 관리 일정 백그라운드 실행 | 원본 제외, 예약 작업 없음 |
| 서명키·비밀번호·실제 광고 ID | 포함하지 않음 |
| APK/AAB·실제 사용자 DB·개인 백업 | 포함하지 않음 |
| 디자인 리소스·예시 화면 이미지 | 공개 |

이 저장소는 출시 프로젝트의 Git 이력을 가져오지 않고, 선정한 파일로 처음부터 구성했습니다. 원본 Android Studio 프로젝트는 별도로 유지됩니다.

화면 이미지는 실제 앱에 가상의 예시 기록을 넣어 촬영했습니다. 저장소의 메모리 데이터도 가상 예시입니다. 공개 데모에 저장한 내용은 영구 저장되지 않습니다.

`.gitignore`는 개발 환경·빌드 결과·키·DB 등을 제외하도록 구성했습니다. 제외 규칙만 믿고 파일을 포함하지 않고, 공개 파일 목록과 내용도 별도로 확인했습니다.
