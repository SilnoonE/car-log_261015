# 공개 데모 검증

정식 앱과 공개 데모는 별도 패키지와 구현을 사용합니다. 정식 앱의 저장·광고·알림 테스트 결과를 공개 데모의 검증 결과로 대신하지 않습니다.

## 공개본 확인 항목

- debug 앱 및 instrumentation 테스트 앱 빌드
- 월별 보고서의 연도 구분, 잘못된 금액·미래 날짜 거부, 완료 일정 제외: 단위 테스트 3개
- 예시 데이터를 사용해 기록·통계·내 차·홈을 탐색하고 총지출 확인: UI 테스트 1개
- 공개 파일의 키·광고 ID·운영 환경 값 및 비공개 핵심 구현 잔존 여부 점검

```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest
./gradlew :app:connectedDebugAndroidTest
```

기기 테스트는 별도의 `com.silnoone.chagok.demo` 패키지에서 실행합니다. 공식 앱이나 기존 개발 패키지의 데이터에 접근하지 않습니다.

정식 앱에서는 저장·복원·입력·화면 이동·광고·알림을 별도로 검증했습니다. 해당 기능의 실제 구현과 테스트는 공개 저장소에서 제외했습니다.
